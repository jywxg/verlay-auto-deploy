# verlay 部署到 Vercel（一键部署）

## 快速开始

1. 把下面仓库 fork 到自己的 GitHub 账号  
2. 把以下信息发给我：
   - Vercel Token（vcp_ 开头）
   - 部署国家（可选，默认 JP）
   - 自定义域名（可选）

3. 等我部署好后，我会返回最终订阅链接。
